FAQ

Won't Nintendo take this game down?

Nintendo only takes down fangames that make a profit or are remakes of existing games. Besides, SMBX, the engine this is made in, has existed for many years and has never once been taken down.

Why make a fangame and not an original game?

This project is a big passion project and love letter to the Mario RPGs. We have ideas for an original game in the future, but this something we currently enjoy working on.

What's the difference between 'Full' and 'Episode' on the download page?

''Full'' includes SMBX2, a Mario fan game engine, which is needed to play. ''Episode'' just downloads the game only, which is for people that already have SMBX2 installed.

Will the game be ported to other platforms like Android?

No. The engine unfortunately is not able to be ported.

Are multiple languages supported?

Right now it's just English, but more languages will be supported in future updates.

Is Mario the only playable character?

Yes. But the game does have segments where you play as others, akin to Paper Mario.

When is the full game releasing?

When it's ready. Our current release structure is releasing each new chapter when it's finished.

When did this project start development?

Originally started as a bunch of early level concepts in 2018, the project evolved a LOT since then. A demo was eventually released in early 2023 using the SMBX38a engine, but we later remade it entirely using the newer and more advanced SMBX2 engine, where the new demo 2 (hence the 2) was released in August 2024!

How do I support the project?

The best way to support us is by spreading the game around, like with videos or art. Any support helps, just not anything monetary, since that could get us in trouble!
